# Pipeline

## Research rules (non-negotiable)

- Never invent investor names, firms, partners, check sizes, theses, or portfolio companies.
- Research with search tools: the fund's own site, partner pages, public portfolio, recent announcements, public filings. Record the source URL and the date checked.
- Anything not confirmed from a source gets `[UNVERIFIED]`. The founder re-verifies before outreach; partners move and theses change.
- Check portfolio conflicts: a direct competitor in their portfolio usually rules them out.
- If no search tool is available, give the founder the criteria and an empty CRM; do not fill rows from memory.

## Target list criteria

| Criterion | Question | Disqualifies if |
|---|---|---|
| Stage | Do they invest at pre-seed / seed now? | Only Series A+ in last 12–18 months |
| Check size | Typical first check | Range is far from the round's needs |
| Lead vs follow | Do they set terms and lead? | Need a lead and they only follow (keep as follow-on) |
| Thesis / sector | Do they publicly focus on this space or model? | Explicit exclusion |
| Geography | Do they invest where the company is incorporated / operates? | Explicit exclusion |
| Activity | New investments in the last 12 months? | No recent activity (fund may be fully deployed) |
| Conflict | Competitor in portfolio? | Direct competitor |
| Path in | Who can make a warm intro? | Not disqualifying; affects tier |

Investor types to consider: angels (operators in the space), angel syndicates, pre-seed/seed funds, accelerators, sector-specialist funds, multi-stage funds' seed programmes. Leads are usually funds or experienced angels who set terms.

## Tiers

- **A:** strong fit on all criteria, warm path exists. Meet in the compressed window.
- **B:** good fit, weaker path or partial thesis fit. Meet first for practice and signal.
- **C:** possible follow-on or long shot. Approach after a lead emerges.

## Warm intro request

**Note to connector (short, easy to decline):**
```
Hi <connector>,
We're raising a <$ range> <pre-seed/seed> for <Company> (<one-liner>). <Investor> at <Firm>
looks like a strong fit because <specific, sourced reason>. Would you be comfortable checking
whether they'd like an intro? Blurb below to forward. No problem at all if not.
<Founder>
```

**Forwardable blurb (≤120 words, only facts from company.md):**
```
<Company> helps <customer> <do job> without <pain>. <Strongest evidence: number with period>.
<Founder> previously <one proof line>. We're raising <$ range> to reach <milestone> by
<month/quarter>. We'd like to talk to <Investor> because <specific reason>. Deck available on request.
```

Rules: one intro request per connector per message; never ask a connector for more than ~2 intros at once; follow up once after 5–7 days, then drop.

## Process timeline (typical; adjust to context)

| Week | Activity |
|---|---|
| −4 to −2 | Readiness, deck, list, data room, warm-up updates |
| −2 to 0 | Request intros; 3–5 B-tier meetings |
| 1–3 | A-tier first meetings in a compressed window |
| 3–5 | Second meetings, partner meetings, diligence |
| 5–8 | Term sheet / lead commit, fill the round, close |

If after ~20–30 qualified first meetings there is no second-meeting momentum, stop and diagnose (story, evidence, or targeting) before burning more of the list.

## Follow-up templates

**Same-day thank you:**
```
Thanks for the time today, <name>. As promised: <item>. On <their question>, <short answer
or "we'll have that by <date>">. Our process: <honest status, e.g. "first meetings this week
and next">. Happy to set up <next step>.
```

**After a pass:** thank them, ask for one piece of feedback, ask if they want monthly updates.

## Closing checklist
- Lead terms agreed and documented by counsel.
- Allocation tracked against target; minimum close amount reached.
- Signed documents collected; countersigned copies returned.
- Funds received and reconciled against each investor.
- Cap table updated.
- Journal entry: date, amount, instrument, key terms, investors.

## Data room checklist

Prepare before A-tier meetings; share after real interest. Mark items not yet available `[NEED: ...]`.

**Company**
- Incorporation documents, cap table (fully diluted), prior financing documents (SAFEs, notes), board/shareholder approvals
- IP assignment agreements for all founders and contributors

**Financial**
- Monthly P&L and cash for the last 12 months (or since inception)
- Current burn and runway calculation
- Financial plan / model for the round period, assumptions labelled

**Commercial**
- Metrics dashboard with definitions (same as investor updates)
- Customer list (with permission) and key contracts or LOIs
- Cohort / retention data if available
- Pipeline (B2B)

**Product and team**
- Product demo or video, roadmap for the round period
- Team list, roles, equity, hiring plan
- Key policies relevant to the sector (privacy, security, regulatory)

**Deck**
- Send-ahead deck, presented deck, one-page memo
